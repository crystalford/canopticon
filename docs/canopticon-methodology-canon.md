# CANOPTICON Methodology Canon

**The thinking traditions that should shape how the system reasons**

*Assembled from research and verified knowledge; this is the complement to the earlier Structured Analytic Techniques roadmap. Where the prior report covered intelligence-community tradecraft (ACH, Key Assumptions Check, Admiralty grading) and forecasting/rationalist disciplines (Brier, Scout Mindset, double-crux), this document covers the wider canon: creative-thinking methods, philosophical epistemology, psychological frameworks, systems thinking, dialectical traditions, and non-Western reasoning.*

---

## How to read this

Each tradition is described with three elements: **what it is**, **what it contributes methodologically**, and **how CANOPTICON should integrate it** — not as a separate agent but as part of how the system thinks.

The goal is not to implement 60 frameworks. The goal is to have them *available* as a canon, so that when a specific type of question arises — a contested scientific claim, an ideologically-loaded contradiction, a systems-level policy question, a deeply-ambiguous pattern — the system knows which tradition to draw from.

Frameworks are grouped by family. At the end, a ranked shortlist identifies which 12 should be first-class integrations and which should sit in the canon for situational use.

## Part I — Creative and Lateral Thinking

### 1. Edward de Bono — Six Thinking Hats

Developed by Maltese physician Edward de Bono in 1985, Six Thinking Hats is a **parallel-thinking discipline**: everyone in a discussion thinks in the same mode at the same time, cycling through six modes rather than arguing across modes. The colors are:

- **White** — facts, data, information gaps. What do we know, what do we need?
- **Red** — emotions, intuition, gut reactions. No justification required.
- **Black** — caution, risks, critical judgment. What could go wrong?
- **Yellow** — optimism, benefits, value. Where's the upside?
- **Green** — creativity, alternatives, new ideas. What else?
- **Blue** — process control, meta-thinking. Managing the thinking itself.

The core insight is that adversarial thinking ("you're wrong, here's why") is often a failure mode of group reasoning. Parallel thinking forces everyone to engage the same facet at the same time, which prevents the ego/combat dynamic and produces more complete analysis.

**Honest caveat**: de Bono's empirical evidence base is thin. A Cambridge-led evaluation of 42 thinking frameworks found "sparse research evidence" that training in Six Thinking Hats produces generalized thinking improvements. The method is useful as a *discipline* more than as a proven cognitive upgrade.

**Integration for CANOPTICON**: When analyzing a thesis, the system can generate six parallel passes on the same claim — facts pass, emotional/intuitive-reading pass, risk/objection pass, benefit/affordance pass, creative-alternative pass, meta-pass ("what's the thinking missing?"). This is distinct from adversarial red-teaming because all six passes are held as legitimate simultaneous contributions, not as combatants.

### 2. Edward de Bono — Lateral Thinking and Po

De Bono's earlier and arguably more original contribution (1967): lateral thinking is generating ideas by moving *sideways* through conceptual space rather than digging deeper in the current direction. The tool he invented for this is **Po** — a provocation operator that deliberately proposes something unreasonable or non-sequitur to force the mind to jump tracks. "Po: cars should have square wheels." The point isn't to solve square wheels — it's that considering the provocation surfaces ideas (shock absorbers, terrain responsiveness, redundant suspension) that straightforward analysis wouldn't reach.

**Integration**: CANOPTICON can have a Po operator — deliberately inject a reversed, exaggerated, or absurd version of a claim to surface adjacent hypotheses the system wouldn't otherwise generate. For a thesis like "Carney's program is monetary restructuring," Po-provocations might be: "Po: Carney is a populist"; "Po: the architecture was designed by environmentalists against his will"; "Po: Canada doesn't exist." The productive ones surface new angles.

### 3. Alex Osborn — Brainstorming

Osborn's 1939 formulation — defer judgment, go for quantity, build on others' ideas, welcome the wild — is now so ingrained that it's invisible. But the discipline of *deferring judgment* specifically is counterintuitive and violated more than followed. Subsequent research (particularly Paulus and colleagues) shows that most "brainstorming" underperforms individual ideation precisely because judgment isn't actually deferred.

**Integration**: Generation and evaluation should be strictly separated as phases in any CANOPTICON workflow. During generation, no claim is graded, no hypothesis is eliminated, no Admiralty score is assigned. Grading happens in a subsequent pass. Mixing the phases kills generation.

### 4. SCAMPER

A checklist-style creativity tool developed by Bob Eberle in 1971 based on Osborn's work. For any claim or idea, apply:

- **S**ubstitute — what could be swapped?
- **C**ombine — what could be joined?
- **A**dapt — what from elsewhere fits?
- **M**odify (magnify/minify) — bigger, smaller, exaggerated?
- **P**ut to other uses — what else could this do?
- **E**liminate — what if removed?
- **R**everse — what if flipped?

**Integration**: SCAMPER on a political thesis produces adjacent hypotheses cheaply. If the thesis is "Brookfield benefits from the transition architecture," SCAMPER yields: Substitute (who else benefits?), Combine (which benefits combine?), Adapt (what analogous architectures exist?), Eliminate (what if Brookfield weren't in it?), Reverse (who *loses* from the transition?). Trivial to automate as a prompt template.

### 5. TRIZ — Theory of Inventive Problem Solving

Developed by Soviet engineer Genrich Altshuller (1946 onward) after analyzing 200,000+ patents. TRIZ's core insight is that most engineering problems reduce to resolving **contradictions** — situations where improving one parameter degrades another — and that history has already produced ~40 inventive principles that recur across domains. Altshuller codified these into a contradiction matrix: given parameters in tension, look up which principles historically resolved similar tensions.

**Integration**: Political-economy analysis constantly deals with contradictions — between accountability and speed, between sovereignty and integration, between decarbonization and growth. TRIZ-style contradiction cataloging would identify, for each CANOPTICON thesis, the structural tensions it rests on and the historical patterns of how similar tensions have been resolved (or haven't). A "contradiction table" would be a valuable graph structure parallel to the claim graph.

### 6. Design thinking (Stanford d.school / IDEO)

Five stages: **empathize, define, ideate, prototype, test** — with explicit emphasis that the stages aren't linear but iterate. The methodological contribution isn't the stages themselves but the commitment to keep cycling between problem-definition and solution-generation rather than committing early.

**Integration**: CANOPTICON's investigative workflows often fail by locking onto a thesis too early. A "keep the problem open" discipline — formalized as a trigger that reopens problem-definition after N solution attempts — would counter this.

### 7. Arthur Koestler — Bisociation

In *The Act of Creation* (1964), Koestler argued creative thought is the *bisociation* of two unrelated matrices of thought — the sudden connection between previously unrelated domains. Humor, scientific discovery, and artistic metaphor all share this structure: two frames collide, producing a third thing.

**Integration**: Cross-domain connection — explicitly tagging when a claim connects patterns across unrelated fields (political/economic with biological/ecological, for instance) — is where the highest-value insights come from. CANOPTICON should reward and surface bisociative connections. This is the same idea as structural holes in network theory, from a different tradition.

### 8. Mihaly Csikszentmihalyi — Systems model of creativity

Csikszentmihalyi argued creativity isn't a property of individuals but of a three-part system: **individual** (person with knowledge + motivation), **domain** (the body of knowledge and techniques), **field** (the gatekeepers and evaluators). A creative contribution exists only when all three align — the individual produces something novel *that the field recognizes as advancing the domain*.

**Integration for CANOPTICON**: This is a reminder that analytical output is evaluated by a field, not just by internal rigor. The "who gates this claim?" question becomes structural: which field is the relevant evaluator (academic economics? journalism? policy wonks? investment community?), and does our claim meet their standards? Different claims have different relevant fields and different reception criteria.

## Part II — Philosophical Epistemology

### 9. Socratic method (Plato)

The elenchus: structured questioning that exposes the contradiction in an interlocutor's position, leading to aporia (productive confusion) as the precondition for genuine understanding. Socrates didn't teach — he made people realize they didn't know what they thought they knew.

**Integration**: A Socratic agent that, for each confident CANOPTICON claim, generates the sequence of questions that would expose hidden assumptions. Not "is this true?" but "what would have to be the case for this to be true? And is that actually the case?" — recursive until bedrock or contradiction. This is formally related to Toulmin warrant-surfacing and to Key Assumptions Check, but older and more disciplined.

### 10. Aristotle — Four causes and phronesis

Aristotle distinguished four causes of any thing: **material** (what it's made of), **formal** (its structure/pattern), **efficient** (what brought it about), **final** (its purpose/end). Modern science has largely abandoned final cause but it remains essential for understanding *human* systems, where purpose is real.

He also distinguished three kinds of knowledge: **episteme** (scientific/universal), **techne** (craft/productive), **phronesis** (practical wisdom — knowing what to do in particular circumstances). Most political intelligence is phronetic, not epistemic.

**Integration**: For every major claim about a political actor or institution, the system should explicitly identify the four causes — especially final cause, because political analysis that misses *what actors are actually trying to accomplish* is systematically confused. The episteme/techne/phronesis distinction tells CANOPTICON that Brier calibration on political-judgment claims is inherently different from calibration on scientific claims. Phronesis cannot be reduced to rules; it's the seasoned practitioner's situational judgment.

### 11. Francis Bacon — Idols of the mind

In *Novum Organum* (1620), Bacon identified four systematic sources of error:

- **Idols of the Tribe** — errors common to human nature (pattern-finding where none exists, etc.)
- **Idols of the Cave** — errors from the individual's own history and disposition
- **Idols of the Marketplace** — errors from language and misnaming
- **Idols of the Theatre** — errors from received systems and dogmas

**Integration**: A routine bias-check that runs the "idols" inventory against any conclusion. The Marketplace check is particularly valuable for political analysis — are we being trapped by the words we inherited (e.g., "net-zero," "transition," "emergency")?

### 12. Charles Sanders Peirce — Three types of inference

Peirce distinguished three modes of inference that most people conflate:

- **Deduction**: from rule and case, the result necessarily follows. "All men are mortal; Socrates is a man; Socrates is mortal." Truth-preserving, adds no new information.
- **Induction**: from case and result, generalize to the rule. Ampliative but fallible.
- **Abduction**: from rule and result, infer the case. "The grass is wet; when it rains the grass gets wet; therefore it probably rained." This is the inference of *hypothesis* — the generation of explanations for observations. It is distinct from inference-to-the-best-explanation (IBE), which is evaluative; abduction proper is generative.

Peirce insisted all three are irreducible. Modern discussion (Gabbay, Woods) has elaborated abduction as central to scientific discovery and medical diagnosis.

**Integration**: CANOPTICON's current claim-handling conflates these. It should explicitly mark each inference: is this a deduction from an established rule? An induction from observed cases? An abduction — a generated hypothesis requiring further testing? Abductions should never be treated as conclusions; they're starting points for testing. Much of what passes as political analysis is abduction presented as induction.

### 13. Karl Popper — Falsificationism

Popper's tetradic scheme: **P1 → TT → EE → P2**. Start with a problem (P1), propose a tentative theory (TT), subject it to error-elimination (EE) — especially attempts to falsify — and arrive at a new problem (P2). Science progresses by bold conjectures and ruthless attempts to refute them. A theory that can't be falsified isn't scientific; a theory that survives genuine falsification attempts earns provisional acceptance.

**Integration**: For every CANOPTICON thesis, explicitly state what would falsify it. If nothing would, the thesis is ideological, not analytical. This is a mandatory field, not a suggestion.

### 14. Thomas Kuhn — Paradigms

Kuhn's *Structure of Scientific Revolutions* (1962) argued science moves through phases of **normal science** (puzzle-solving within a paradigm), accumulating anomalies, then **crisis** and **revolution** (paradigm change), followed by a new normal-science phase. Paradigms are *incommensurable* — adherents of different paradigms talk past each other because their terms don't mean the same things.

**Integration**: Political analysis constantly crosses paradigms (neoliberal/heterodox economics; realist/liberal IR; etc.). CANOPTICON should tag each claim with the paradigm it's operating in, surface when claims from different paradigms appear to contradict but may actually be incommensurable, and flag the rare genuine paradigm conflicts.

### 15. Imre Lakatos — Research programmes

Lakatos refined Popper: what gets evaluated isn't individual theories but research programmes with a **hard core** (immune to refutation by fiat) and a **protective belt** of auxiliary hypotheses that can be modified. A programme is **progressive** if it keeps generating novel predictions that are corroborated; **degenerating** if it only accommodates anomalies by adding ad-hoc hypotheses.

**Integration**: CANOPTICON should track whether each of its long-running theses is progressive or degenerating. If a thesis has accumulated ten protective-belt modifications without generating any novel corroborated prediction, it's probably dying and should be abandoned or reformulated. This is the single most useful meta-diagnostic in philosophy of science.

### 16. Paul Feyerabend — Methodological pluralism

Feyerabend's provocative *Against Method* (1975) argued there's no single scientific method; rigid methodology has historically *held back* progress; creative breakthroughs often violated accepted norms. His slogan "anything goes" is polemical — what he actually meant is that methods have to be fit to the question.

**Integration**: CANOPTICON should resist imposing one methodology across all investigations. Different topics warrant different methods. The methodology canon itself is *anti-monistic*: the system picks from it based on what the question calls for.

### 17. W.V.O. Quine — Web of belief

Quine argued beliefs don't face evidence individually — they face it as an interconnected web, with peripheral beliefs (observations) more easily revised than core beliefs (logic, mathematics). When evidence contradicts a theory, you can always save any given belief by adjusting others. What you *shouldn't* do is save core beliefs by ad-hoc adjustments at the periphery.

**Integration**: When evidence appears to contradict a CANOPTICON claim, the system should make the revision choices explicit: which beliefs are we adjusting and which are we protecting, and is that pattern of protection defensible? This connects directly to Lakatos's progressive/degenerating distinction.

### 18. Wittgenstein — Language games and private language

Later Wittgenstein (*Philosophical Investigations*) argued meaning is use; concepts acquire meaning within language games — rule-governed practices. His private language argument: there can't be a language whose terms are defined by reference to private sensations, because meaning requires public criteria of correctness.

**Integration**: For political terms that do heavy analytical work ("populism," "democracy," "transition," "capitalism"), CANOPTICON should surface the language-game context — what practice is this term embedded in, and does that practice have stable public criteria? Terms that float free of any language game are useful rhetorically but worthless analytically.

### 19. Gadamer — Hermeneutics and fusion of horizons

Hans-Georg Gadamer argued understanding is always *interpretation* and interpretation is always from a horizon of prejudices and presuppositions. You can't interpret from nowhere. Genuine understanding involves the **fusion of horizons** — letting your own framework be altered by encounter with the other's.

**Integration**: CANOPTICON's steelman agent should implement fusion-of-horizons: don't just state the opposing view as its adherents would, but let the operator's own framework be altered by the strongest form of the opposing case. If the steelman doesn't cause some updating of the operator's position, the steelman wasn't strong enough.

### 20. Nagarjuna — Catuṣkoṭi (tetralemma)

The Madhyamaka Buddhist philosopher Nagarjuna (c. 150-250 CE) systematized the **catuṣkoṭi** — four-cornered logic. For any proposition P, there are four positions:

1. P (affirmation)
2. ¬P (negation)
3. P and ¬P (both)
4. Neither P nor ¬P (neither)

Nagarjuna's radical move was to argue that in some cases, *all four* should be rejected — the proposition's very framing is the error.

**Integration**: Classical true/false logic can't handle paraconsistent situations — where evidence points in genuinely contradictory directions, or where the question itself is malformed. Political analysis constantly produces these. "Is Canada a democracy?" may not be a yes/no question. CANOPTICON should explicitly allow catuṣkoṭi handling of some claims: when both answers have strong support, flag as tetralemmic rather than forcing resolution. The "neither" position is especially valuable — sometimes the productive move is *dissolving* the question, not answering it.

### 21. Confucian rectification of names (zhengming)

"If names are not rectified, speech will not be in accordance with things; if speech is not in accordance with things, affairs cannot be successful." Confucius argued that social order requires terms (father, ruler, official) to correspond to actual roles — if a ruler does not rule justly, he is not truly a ruler, and speech that calls him such corrupts the discourse.

**Integration**: A discipline for flagging when a term has drifted from its referent. "Journalist," "non-profit," "independent," "carbon-neutral" are all names that may or may not map to the actual practices they claim. CANOPTICON should run a zhengming check on every institutional noun: does the name correspond to the practice?

## Part III — Psychological Frameworks

### 22. Carl Jung — Archetypes

Jung identified recurring patterns (archetypes) in the collective unconscious that shape human cognition and behavior: Self, Shadow, Anima/Animus, Persona, Wise Old Man, Hero, Trickster, Great Mother, and others. Jungian analysis doesn't just describe individuals — it describes the *roles* being enacted in any situation.

Carol Pearson's 12-archetype framework (Innocent, Explorer, Sage, Hero, Outlaw, Magician, Regular Person, Lover, Jester, Caregiver, Creator, Ruler) is a cleaner modern catalog often used in brand strategy.

**Integration**: Political actors consciously and unconsciously adopt archetypal roles (Hero, Wise Old Man, Outlaw, Ruler). Tagging claims with the archetypal register they invoke — what role is this actor performing, what role is the media casting them in — is a productive interpretive layer. It also helps identify when different actors are being forced into incompatible archetypes by the same narrative.

### 23. Joseph Campbell — Hero's journey

Campbell's monomyth (1949): Call to Adventure → Refusal → Supernatural Aid → Crossing the Threshold → Belly of the Whale → Road of Trials → Meeting the Goddess → Atonement → Apotheosis → Ultimate Boon → Return. The narrative structure appears across wildly different cultures.

**Integration**: Political narratives constantly get shoehorned into hero's-journey structure. Recognizing when a story is being shaped by the monomyth (and therefore distorted relative to messier reality) is an interpretive discipline. A "narrative-structure tag" on claims would flag when analysis is being influenced by story-shape rather than evidence.

### 24. Kahneman — System 1 / System 2

System 1 is fast, automatic, pattern-matching; System 2 is slow, deliberate, effortful. System 1 is competent within trained domains but systematically biased in novel ones; System 2 is costly and prone to fatigue. Most reasoning is System 1 with System 2 offering post-hoc rationalization.

The heuristics-and-biases catalog (Kahneman with Tversky): anchoring, availability, representativeness, framing effects, loss aversion, hindsight bias, confirmation bias, base-rate neglect, conjunction fallacy, planning fallacy. Each is a documented, replicable failure mode of human judgment.

**Integration**: A routine bias-scan on every CANOPTICON conclusion. Was the first number we saw an anchor? Is the case we're reasoning from unusually available because it's recent or vivid? Are we representing the whole from a stereotype? The scan doesn't have to be exhaustive — checklists catch real errors even when most items don't apply.

### 25. Gary Klein — Recognition-primed decision making

Klein's research on firefighters, nurses, chess masters: expert judgment often isn't deliberate at all. Experts recognize situations as similar to ones they've handled before, and the response comes pre-formed. This is System 1, but *trained* System 1 — the opposite of Kahneman's bias-ridden default.

**Integration**: This matters because it means not all fast judgments are biased and not all slow ones are accurate. CANOPTICON should distinguish *trained recognition* (an operator with deep domain experience spotting a pattern) from *lazy heuristic* (anchoring on the first number available). The former is valuable; the latter is noise.

### 26. Internal Family Systems (Richard Schwartz)

IFS models the mind as multiple "parts" — each with its own perspective, emotional tenor, and concerns — around a core Self. Internal dialogue among parts is treated as a legitimate cognitive operation, not a pathology.

**Integration**: Related to the rationalist "internal double-crux" technique. For complex political-economy questions where different parts of the operator's own mind pull in different directions, CANOPTICON can externalize this: generate claims from the "realist part," the "skeptical part," the "ethical part," the "strategist part," and treat the internal dialogue as a structured reasoning process rather than noise to suppress.

### 27. Gestalt psychology

Figure-ground, closure, proximity, similarity, common fate — the Gestaltists identified that perception is *organized* into wholes, not assembled from atomic features. "The whole is other than the sum of the parts" (Kurt Koffka — often misquoted as "greater than").

**Integration**: Political analysis should explicitly ask the Gestalt questions. What's being foregrounded vs. what's the ground it's rendered against? What closure is being performed (filling in gaps to complete a pattern)? What is treated as moving together (common fate) when it might be coincidence? Pattern recognition is valuable, but pattern *over-recognition* is a primary failure mode.

## Part IV — Systems Thinking and Cybernetics

### 28. Norbert Wiener — Cybernetics

Wiener's *Cybernetics* (1948) established the foundational concept: systems regulated by feedback loops can display purposive, goal-directed behavior without requiring any internal "purpose." A thermostat is the canonical example: it has no mind, but it exhibits goal-directedness through feedback.

**Integration**: Every CANOPTICON claim about an institution or system should implicitly or explicitly identify the feedback loops. What inputs does this system sense, what outputs does it produce, what reference point is it regulating toward? Many "conspiracy" analyses of political systems are really just descriptions of negative-feedback regulation the analyst hasn't recognized as such.

### 29. Ross Ashby — Requisite variety

Ashby's Law: a regulator must have at least as much variety (states it can respond with) as the system it regulates. A thermostat with two states (heat on/off) can only regulate a system whose disturbances can be countered with those two states. More complex disturbances require more complex regulators.

**Integration**: When CANOPTICON is analyzing why an institution is failing, requisite variety is often the answer — the regulator lacks the variety to handle the situation. "Government can't keep up with AI" is a requisite-variety claim, whether the analyst realizes it or not.

### 30. Stafford Beer — Viable System Model

Beer's VSM describes any viable system (organism, business, government) as five recursively-embedded subsystems: operations, coordination, control, intelligence, and policy. Each level of an organization should contain all five functions in miniature. Dysfunction typically involves one of the five being crushed or absent.

**Integration**: For analyzing political institutions — ministries, parties, agencies — VSM diagnosis is a rigorous alternative to impressionistic critique. Is the "intelligence" function (environmental scanning) separated from the "control" function (internal coordination)? If not, the institution can't adapt to novel threats. This is a genuinely powerful tool.

### 31. Gregory Bateson — Levels of learning, double bind

Bateson distinguished levels of learning: Learning 0 (immediate reaction), Learning I (trial-and-error within a class of contexts), Learning II (learning about the class itself — meta-learning), Learning III (changing the system of meta-learning). Most analysis operates at Learning I. The interesting insights often happen at II or III.

The **double bind** — being caught between contradictory demands at different logical levels — is Bateson's contribution to understanding certain pathologies (he originally proposed it as a theory of schizophrenia; it applies more broadly to institutions and political situations).

**Integration**: Political actors are often in double binds — contradictory demands where meta-level framing prevents acknowledging the contradiction. CANOPTICON should identify these structurally. "Expand immigration for economic growth" + "hit net-zero through per-capita reduction" is a double bind if treated as a single consistent policy.

### 32. Donella Meadows — Leverage points in systems

Meadows identified twelve leverage points for intervening in systems, ranked from weakest to strongest:

12. Constants, parameters, numbers
11. Buffer sizes
10. Material stocks and flows structure
9. Delays
8. Negative feedback loop strength
7. Positive feedback loop gain
6. Information flow structure
5. System rules
4. Self-organization power
3. System goals
2. Paradigm
1. Transcending paradigms

Most policy interventions operate at 12-8 (parameters, buffers); they have the least impact. Interventions at 3-1 (goals, paradigm) have the most. But they also generate the most resistance.

**Integration**: Every policy claim CANOPTICON analyzes should be tagged with its leverage-point level. "Adjust the carbon tax rate" is a 12. "Change who we're trying to benefit from climate policy" is a 3. Surfacing the leverage-point level of interventions immediately shows which ones are tweaks and which are paradigm challenges — which maps directly to why certain interventions meet overwhelming resistance and others slide through.

### 33. Peter Senge — Systems archetypes

Senge catalogued recurring generic patterns in social systems: **Limits to Growth**, **Shifting the Burden**, **Tragedy of the Commons**, **Fixes That Fail**, **Eroding Goals**, **Escalation**, **Success to the Successful**, **Growth and Underinvestment**. Each archetype comes with characteristic causal-loop diagrams and typical intervention advice.

**Integration**: Pattern-matching political-economy situations to systems archetypes is genuinely productive. The "Fixes That Fail" archetype — where short-term fixes create long-term problems — is visible everywhere in climate policy, housing policy, drug policy, immigration policy. Identifying the archetype immediately suggests the intervention (work on the long-term fundamental, don't keep patching the short-term symptom).

### 34. Dave Snowden — Cynefin

Cynefin sorts situations into five domains, each requiring a different decision-making approach:

- **Clear/obvious** (ordered) — cause-and-effect is self-evident. Sense → Categorize → Respond. Use best practice.
- **Complicated** (ordered) — cause-and-effect requires expertise. Sense → Analyze → Respond. Use good practice.
- **Complex** (unordered) — cause-and-effect only retrospectively visible. Probe → Sense → Respond. Emergent practice.
- **Chaotic** (unordered) — no cause-and-effect. Act → Sense → Respond. Novel practice; stabilize first.
- **Confused/aporetic** — you don't know which domain you're in. First establish that.

The critical boundary is between Clear and Chaotic — Snowden calls it a "cliff." Treating a complex situation as clear produces catastrophic failure.

**Integration**: Every investigation CANOPTICON runs should be Cynefin-tagged. The analytical method has to match the domain. A complex political situation (most of them) doesn't respond to analyze-then-act. It responds to probe-sense-respond — small experiments, watch what emerges, amplify what works. Most policy failure is domain-misdiagnosis.

### 35. John Boyd — OODA loop

Observe → Orient → Decide → Act — but Boyd's crucial insight was that **Orient** is not neutral; it's shaped by cultural traditions, previous experience, and genetic heritage. And whoever can cycle through the loop faster dominates — because they're acting on an updated orientation while the opponent is still acting on stale orientation.

**Integration**: For adversarial/strategic analysis (political competition, media response, crisis management), OODA is the frame. CANOPTICON should track OODA-cycle speed as a variable — how fast can this actor observe, orient, decide, act? Carney's government orienting in hours on carbon-tax repeal is a different OODA cycle than the bureaucratic apparatus beneath it. Mismatches in OODA speed between levels of a system are highly diagnostic.

### 36. W. Edwards Deming — System of Profound Knowledge + PDCA

Deming's SoPK has four components: **appreciation for a system**, **knowledge about variation**, **theory of knowledge**, **psychology**. His PDCA (Plan-Do-Check-Act) cycle is the operational loop of continuous improvement.

The knowledge-of-variation piece is specifically about distinguishing **common-cause** from **special-cause** variation. Treating common-cause variation (noise within the system) as if it were special-cause (signal worth responding to) is tampering — making the system worse by over-responding to noise.

**Integration**: This is important for how CANOPTICON handles data. Political metrics are noisy. Responding to every fluctuation as if it were signal is tampering. The system should estimate the common-cause variation band for each metric and only flag movements outside it as signal.

### 37. Russell Ackoff — Mess

Ackoff argued most real-world problems aren't problems at all — they're **messes**. A mess is a system of interrelated problems. You can't solve any one without changing the others. Treating a mess as if it were a single solvable problem is category error.

**Integration**: Many CANOPTICON questions are messes (climate/immigration/housing/inequality). The methodology should explicitly flag when a question is a mess rather than a problem, and shift to mess-management (interactive planning, continuous adjustment, managing tradeoffs) rather than pretending it's a soluble problem.

## Part V — Dialectical and Argumentative Traditions

### 38. Hegel — Dialectical method

The Fichte-Hegel formulation (thesis → antithesis → synthesis) is a simplification, but captures the key move: genuine understanding emerges by holding two opposed positions together until their limits reveal a third position that *aufgehoben*-preserves-and-transcends both. The German word has no English equivalent; it simultaneously means "abolish," "preserve," and "elevate."

**Integration**: Stronger than adversarial reasoning. Not "debate between thesis and antithesis" but "patient sitting-with-both until synthesis emerges." For deeply contested political-economy questions, CANOPTICON should be able to explicitly run a Hegelian move: fully develop thesis and antithesis, identify where each breaks down on its own terms, and generate the synthesis that preserves what each got right.

### 39. Aristotle — Rhetoric (ethos, pathos, logos)

Aristotle's three rhetorical appeals: **ethos** (credibility of the speaker), **pathos** (emotional state of the audience), **logos** (logical structure of the argument). Political persuasion operates on all three; analysis that only examines logos misses most of what's happening.

**Integration**: CANOPTICON's content analysis should decompose communications into ethos/pathos/logos contributions. A speech is rarely just logical argument; it's credibility-performance plus emotional frame plus argumentative content. Missing the first two produces systematically wrong interpretations of political communication.

### 40. Toulmin — Argument structure (already in prior research)

Claim, Grounds, Warrant, Backing, Qualifier, Rebuttal. Covered in the prior methodology report. The critical element is the Warrant — the often-unstated assumption connecting grounds to claim.

### 41. Douglas Walton — Argumentation schemes

Walton catalogued ~60 argumentation schemes — recurring patterns like "argument from expert opinion," "argument from analogy," "argument from consequences," "slippery slope argument." Each scheme has **critical questions** — the standard moves by which the scheme can be contested.

**Integration**: For every CANOPTICON claim derived via a standard pattern (most are), the system should identify the argumentation scheme and the critical questions for that scheme. "This is an argument from expert opinion. Critical questions: Is the expert credible? Is this within their domain? Do other experts disagree?" This is a ready-made disciplined adversarial check.

### 42. John Stuart Mill — Methods of induction

Mill's five methods for inferring causation from observation:

- **Agreement**: If X precedes Y in all cases, X may cause Y.
- **Difference**: If removing X removes Y, X may cause Y.
- **Joint method** (agreement + difference combined).
- **Residues**: Subtract known causes; remainder has the remaining effect.
- **Concomitant variations**: If X varies with Y, they may be causally linked.

**Integration**: For empirical-causal claims, CANOPTICON should explicitly identify which of Mill's methods is underwriting the inference — and whether the conditions for that method are actually met. Most "this caused that" claims in political analysis fail Mill's conditions.

### 43. Legal reasoning — IRAC and analogical casuistry

**Issue, Rule, Application, Conclusion** is the standard legal-analysis template. Its discipline is rigorous identification of the *rule* that applies before reasoning about the facts. Common-law analogical reasoning — deciding present cases by comparing to precedent — is a distinct methodology with its own rigor (identifying the *ratio decidendi* of the precedent, distinguishing the present case from it).

**Integration**: For CANOPTICON claims that involve regulatory, constitutional, or contractual matters, IRAC structure should be mandatory. The rule-first discipline prevents conflation of "what the law says" with "what I think is right."

### 44. Talmudic reasoning (pilpul, machloket)

The Talmud preserves centuries of multi-voice debate without resolving most disputes — a tradition called **machloket l'shem shamayim** (dispute for the sake of heaven). Arguments on both sides of a contested question are preserved and reasoned about dialectically across generations. **Pilpul** is the sharp analytical technique of surfacing fine distinctions between apparently-similar positions.

**Integration**: For contested political-economy questions where no resolution is forthcoming, CANOPTICON should explicitly adopt the machloket posture: preserve both positions as valid interlocutors, refine them over time, don't force closure. This is distinct from both "neutrality" and "false balance" — it's a disciplined cultivation of productive disagreement.

### 45. Scholastic method — Quaestio and disputatio

The medieval scholastic template for examining any question: state the question, enumerate objections (usually the strongest available), offer a contrary authority ("sed contra"), provide the teacher's resolution, then individually answer each objection. Aquinas's *Summa* is the canonical example — relentless, exhaustive, and honest about counterarguments.

**Integration**: This is an excellent template for long-form CANOPTICON analyses. Each major thesis should be presented as a quaestio: the question, the strongest objections (not strawmen), the contrary authority, the author's resolution, and explicit responses to each objection. It's much more rigorous than the standard essay form.

## Part VI — Narrative and Framing

### 46. Kenneth Burke — Dramatistic pentad

Every act can be analyzed via five terms: **Act** (what happened), **Scene** (where/when), **Agent** (who), **Agency** (by what means), **Purpose** (why). Different rhetorical framings emphasize different ratios among these terms (scene-act, agent-act, etc.). Burke argued most ideological disputes can be described as disagreements about which pentadic ratio applies.

**Integration**: For any reported political event, CANOPTICON can run the pentad and identify which terms are being emphasized by which sources. "The policy happened" (act-focused) vs. "Carney did this" (agent-focused) vs. "The market required it" (scene-focused) are very different framings of the same event. The pentad surfaces the framing systematically.

### 47. George Lakoff — Framing and conceptual metaphor

Lakoff argues political cognition is dominated by conceptual metaphors (nation-as-family, government-as-parent, economy-as-machine, etc.) that precede and shape explicit reasoning. His strict-father vs. nurturant-parent framework is his specific contribution to American political analysis.

**Integration**: CANOPTICON should surface the conceptual metaphors each political actor is activating. The metaphor is often more predictive than the explicit position. A "tough-on-crime" rhetoric activates strict-father framing; a "harm-reduction" rhetoric activates nurturant-parent framing — and the actors who speak in each register tend to align across seemingly-unrelated issues.

### 48. Jerome Bruner — Paradigmatic vs. narrative modes

Bruner distinguished two fundamentally different ways the mind makes sense: the **paradigmatic** mode (logical, category-based, scientific) and the **narrative** mode (story-based, particular, time-and-character). Neither is reducible to the other. Both are legitimate, but they produce different kinds of knowledge.

**Integration**: CANOPTICON should explicitly mark which mode a claim is operating in. Narrative claims ("Carney is on a journey from central banker to statesman") aren't bad, but they're not paradigmatic claims and shouldn't be treated as such. Conversely, paradigmatic analysis ("transition finance reduces emissions by X%") shouldn't pretend to capture the narrative truth.

### 49. Carlo Ginzburg — Evidential/conjectural paradigm

Ginzburg noted that a specific *evidential* reasoning style — attention to tiny details, symptoms, clues — emerged in the late 19th century simultaneously in art attribution (Morelli), detective fiction (Conan Doyle's Holmes), and psychoanalysis (Freud). All three share the method: infer causes from marginal, usually-ignored details. It's abductive reasoning in practice.

**Integration**: The CANOPTICON equivalent is "what tiny detail here doesn't fit the standard story, and what would have to be true for that detail to exist?" This is classic investigative journalism — the throwaway detail is the lede. The system should reward attention to anomalous small facts.

## Part VII — Strategic and Organizational

### 50. Sun Tzu — Art of War

Sun Tzu's core methodological contributions aren't tactical but **epistemic**: know yourself, know your enemy; victory in advance of battle through preparation; shape the situation so the opponent can't win; strike where unprepared, appear where unexpected. The discipline is patience and information advantage, not force.

**Integration**: For strategic/competitive analysis, CANOPTICON should structure analyses around the four quadrants: what does each side know about itself, about the other, and what's hidden from each? Most strategic surprise comes from a party knowing something about its opponent that the opponent doesn't know about itself.

### 51. Clausewitz — Fog of war, friction, trinity

**Fog of war**: in action, information is always partial, late, contradictory. **Friction**: everything is harder than it should be; tiny obstacles accumulate into major delays. **Trinity**: war is governed by the interplay of passion (people), chance (commander/army), and reason (policy/state). Missing any of these produces bad analysis.

**Integration**: CANOPTICON analysis of any action-under-uncertainty should respect fog and friction. "Why didn't they do X?" often has the answer "because in the fog it wasn't visible and the friction made it expensive." This is distinct from incompetence or conspiracy.

### 52. Pierre Wack / Shell — Scenario planning

Wack's insight at Shell in the 1970s: scenarios aren't predictions — they're *interventions in managers' mental models*. A good scenario forces executives to imagine a world different from the one they assume. Shell's anticipation of the 1973 oil crisis came not from predicting it but from having executives who had seriously imagined it.

**Integration**: For forward-looking CANOPTICON analysis, generate scenarios (typically 2-4, in a 2x2 matrix of the two most-uncertain-and-impactful drivers) as *model-shifting exercises*, not forecasts. The question isn't "will this happen?" but "if it did, what would we have missed?"

### 53. Nassim Taleb — Antifragility, via negativa, skin in the game

**Antifragility**: some systems gain from disorder; some degrade; some are fragile. The category matters more than expected-value calculations. **Via negativa**: you know more reliably what doesn't work than what does; subtract, don't add. **Skin in the game**: only trust analysts who bear consequences of being wrong.

**Integration**: Taleb's skin-in-the-game maps directly to public Brier scoring — the discipline Tetlock pioneered. CANOPTICON's public prediction log is its skin in the game. Via negativa — identifying what to eliminate — is often more productive than identifying what to add.

## Part VIII — Contemplative and Reflective Traditions

### 54. Stoic practices — View from above, premeditatio malorum

Marcus Aurelius's Meditations contains two powerful reasoning disciplines. **View from above**: imaginatively ascend to see one's concerns from great distance — what really matters at that scale? **Premeditatio malorum**: rehearse the worst outcomes in advance to (a) emotionally prepare for them and (b) surface contingencies.

**Integration**: Premeditatio is essentially premortem (which is already in the earlier roadmap). View-from-above is a useful analytical discipline for political commentary — the question "will this matter in 10 years? 50?" often reveals that current intensities are disproportionate to structural importance.

### 55. Zen koan — Paradoxical cognition

Zen masters used paradoxical questions ("what is the sound of one hand clapping?") as teaching devices — not to produce answers but to break conceptual habits and induce direct insight. The method deliberately induces cognitive failure to surface a mode of understanding below or beyond propositional knowledge.

**Integration**: For deeply confused political questions, a koan-style reframing ("what would it mean if no one were in charge?") can break analytic stalls. Not as a primary tool, but as a pattern-breaker when the standard analysis is circling.

### 56. Hindu jnana yoga — Neti-neti

"Not this, not this" — the contemplative practice of identifying the true self by systematically negating everything it is not. Related to apophatic theology in the Christian tradition (Pseudo-Dionysius, Meister Eckhart).

**Integration**: When CANOPTICON is trying to identify what an actor/institution actually is, proceeding by via negativa (what isn't it?) often works better than direct characterization. "Carney is not a climate activist, not a populist, not a traditional liberal, not a conservative..." eventually produces a sharper negative-space portrait than any direct characterization would.

## Part IX — Non-Western and Under-Represented

### 57. Ubuntu — Relational ontology

The sub-Saharan African philosophy summarized in the Nguni Bantu aphorism "umuntu ngumuntu ngabantu" — "a person is a person through other persons." Personhood, reasoning, and decision-making are constitutively relational rather than individual.

**Integration**: For analyses of collective action and political coalition, Ubuntu-style framing treats individuals as nodes in relational fields rather than as autonomous agents. This is closer to social network analysis than to rational-choice theory. It's also a critique of methodological individualism that has analytic traction.

### 58. Indigenous reasoning — Seven-generation thinking

Many Indigenous traditions (Haudenosaunee most famously) incorporate seven-generation thinking: decisions evaluated by their impact on descendants seven generations forward. This is a specific discipline, not a general sentiment — it forces a time-horizon most political analysis doesn't consider.

**Integration**: For policy analysis, seven-generation tagging asks: what is the 150-200 year trajectory of this decision? Most policies can't survive this question, which itself is diagnostic.

### 59. Chinese strategic reasoning — Shi

The concept of **shi** in Chinese strategic thought (Sun Tzu onward, developed in François Jullien's analysis): the *configuration* of a situation, the *potential* of a position. Western strategy tends to think in terms of forces and counter-forces; shi thinks in terms of configurations that make certain outcomes flow naturally without requiring force.

**Integration**: For strategic analysis, shi is a distinct concept from "leverage" or "power" — it's the question of what the terrain itself is shaped to produce. A shi analysis of the carbon-finance architecture would identify what configurations make certain outcomes flow naturally regardless of individual intention.

### 60. Polynesian wayfinding — Multi-indicator navigation

Polynesian navigators crossed thousands of miles of open ocean without instruments by reading a dozen simultaneous indicators: wave refraction patterns, cloud shapes, bird behaviors, star positions, water color, wind patterns. No single indicator suffices; the navigator integrates many weak signals into a continuously-updated position estimate.

**Integration**: This is the canonical model for analytical integration of weak signals under uncertainty. CANOPTICON's indicator registry (already in the prior roadmap) should be structured this way: never rely on one signal; continuously integrate many weak ones; accept that the position estimate is always provisional.

## Part X — Scientific Reasoning Disciplines

### 61. Einstein — Gedankenexperiment

Thought experiments as rigorous analytical tools — imagining physically-impossible but logically-consistent scenarios to surface what the theory requires. "What would happen if I rode a light beam?" "What would I observe in a free-falling elevator?"

**Integration**: Thought experiments work for political analysis too. "What would the Canadian political economy look like if there were no immigration?" "What would the carbon architecture look like if Brookfield didn't exist?" These aren't predictions — they're tools for surfacing what current arrangements are actually doing.

### 62. Polya — How to Solve It

Polya's four phases (1945): understand the problem, devise a plan, carry out the plan, look back. His catalog of heuristics — work backward from the goal, find a related problem already solved, generalize, specialize, decompose — is the canonical guide to mathematical problem-solving, but generalizes to all analysis.

**Integration**: The "look back" step is the most underused. After completing an analysis, explicitly review: was the problem correctly framed? Is the answer reasonable? Does the method generalize? Most analytical errors are caught at "look back," not during the main analysis. This is a mandatory discipline.

### 63. Ian Hacking — Styles of scientific reasoning

Hacking identified six distinct "styles" that have emerged in Western science: postulational/mathematical, experimental/laboratory, hypothetical modeling, taxonomic/classificatory, statistical/probabilistic, and historical-genetic/evolutionary. Each has its own criteria for what counts as evidence.

**Integration**: For cross-disciplinary claims, CANOPTICON should identify which style is operating. A claim about causation derived from experimental intervention is a different kind of knowledge than one derived from statistical association or from historical-genetic reconstruction — and they can be combined, but not simply conflated.

### 64. Fermi estimation

Order-of-magnitude estimation under radical uncertainty. Break an unknown quantity into components, estimate each within a factor of 2-3, multiply, and you typically get within a factor of 10 — good enough for many decisions.

**Integration**: CANOPTICON should run Fermi estimates whenever numeric claims are made, as a sanity check. "This costs $X billion" should always trigger an independent Fermi calculation. If the two diverge by more than an order of magnitude, at least one is wrong.

### 65. Mental models / Craik / Johnson-Laird

Philip Johnson-Laird's mental-models theory: reasoning isn't formal logic applied to propositions; people build mental simulations and run them. Kenneth Craik (1943) originally proposed that the mind represents the world in "small-scale models" that can be manipulated to predict consequences.

**Integration**: For analyzing political actors' behavior, CANOPTICON should explicitly model their mental models — what simulation are they running, what do they believe the world is like? This is usually more predictive than attributing explicit beliefs or goals.

## Cross-tradition synthesis: what converges, what diverges

**Strong convergence (multiple traditions point to the same move):**

- **Make the implicit explicit.** Toulmin's warrant-surfacing, Bacon's idols, Key Assumptions Check, zhengming (rectification of names), Wittgenstein on language games — all different traditions, same fundamental move: surface what's being assumed, evaluated, or treated as self-evident.

- **Hold opposites together.** Hegelian dialectic, Nagarjuna's catuṣkoṭi, Talmudic machloket, de Bono's parallel hats, Kahneman-style adversarial collaboration. Different traditions, same recognition that premature resolution produces worse analysis than patient coexistence of contraries.

- **Separate generation from evaluation.** Osborn's brainstorming, design thinking's diverge-then-converge, Peirce's distinction between abduction (generative) and the subsequent testing — all insist on keeping creation phases and judgment phases distinct.

- **Pattern-match to archetypes.** Jungian archetypes, Campbell's monomyth, Senge's systems archetypes, Walton's argumentation schemes, Ginzburg's evidential paradigm. The recurring move is: this particular situation is an instance of a general pattern, and knowing the pattern tells us what to look for.

- **Match method to domain.** Cynefin's domains, Feyerabend's pluralism, Hacking's styles, Bruner's paradigmatic vs. narrative. No single methodology fits all questions; the meta-skill is selecting which to apply.

**Genuine divergence (different traditions disagree):**

- **Resolution vs. productive irresolution.** Analytic philosophy and scientific reasoning try to resolve contradictions; Talmudic reasoning, Nagarjuna's catuṣkoṭi, and Hegel's dialectic treat some contradictions as irreducible or productive.

- **Individual vs. relational reasoning.** Cartesian, analytic, rational-choice traditions center the individual reasoner. Ubuntu, Confucianism, hermeneutic traditions, systems thinking center the relational field.

- **Fast vs. slow.** Klein's recognition-primed decision-making trusts trained intuition; Kahneman's System 2 distrusts it. Both are right in different domains (experts in their domain; amateurs in novel domains).

- **Reduction vs. emergence.** Pearl's causal DAGs, analytical philosophy, and reductionist traditions prefer decomposition. Gestalt, systems thinking, complexity theory, and Eastern traditions insist emergence is real and irreducible.

## Five deep-dive frameworks worth immediate implementation

### Deep Dive 1: Cynefin domain-tagging

**Why it matters**: Most analytical failure comes from method-domain mismatch. Treating a complex situation as if it were complicated is the single most common professional error in policy, politics, and strategy.

**Implementation**: A mandatory classification step before every major investigation. The system asks: is this Clear (best practice applies), Complicated (expert analysis will find the answer), Complex (emergence; probe first), Chaotic (stabilize first), or Confused (clarify the domain first)? Different CANOPTICON workflows apply for each.

**Failure mode to avoid**: the "clear-to-chaotic cliff." When analysts assume a situation is clear when it's actually complex or chaotic, catastrophic surprise follows. Active sensing in apparently-clear domains is mandatory.

### Deep Dive 2: Lakatos's progressive/degenerating diagnosis

**Why it matters**: Distinguishes live theses (still generating novel corroborated predictions) from zombies (only accommodating anomalies via ad-hoc auxiliary hypotheses). Most pundit analysis is the latter without realizing it.

**Implementation**: For every long-running CANOPTICON thesis, maintain a ledger: novel predictions made, corroborated, falsified; auxiliary hypotheses added over time. If the auxiliary-hypothesis-addition rate exceeds the corroboration rate over some window, flag as degenerating.

**Failure mode**: mistaking *accommodation* (making the theory fit the new data post-hoc) for *explanation* (the theory predicted the new data in advance). Only the latter counts.

### Deep Dive 3: Peirce's abduction as first-class inference type

**Why it matters**: Most political analysis is abduction (generating plausible explanations for observations) presented as induction (generalizing from observed patterns). Abductions are hypotheses, not conclusions. Mistaking them produces systematic overconfidence.

**Implementation**: Every claim in CANOPTICON tagged with inference type. Abductions auto-flagged as requiring subsequent testing. Abduction-chains (abduction on top of abduction) flagged as especially weak.

**Failure mode**: abductive chains where each link is plausible but the cumulative probability is tiny. "The simplest explanation is..." said five times in sequence produces very-implausible conclusions.

### Deep Dive 4: Meadows's leverage points

**Why it matters**: Reveals that most policy proposals operate on the weakest leverage points (parameters, delays, buffers) while the ones that would actually change outcomes require working on paradigm, goals, and self-organization — which face massive resistance.

**Implementation**: Every intervention claim CANOPTICON analyzes tagged 1-12. System surfaces the observation when all proposed interventions for a problem cluster at 10-12 — that's itself the finding.

**Failure mode**: treating leverage-point ranking as prescriptive. Lower-numbered leverage points have higher potential impact *and* higher resistance. Sometimes a well-designed parameter change is the best actually-achievable intervention.

### Deep Dive 5: de Bono's Six Hats parallel analysis

**Why it matters**: Forces complete coverage of modes that analytical rigor alone misses (emotion/intuition, gut-level risk, upside, creative alternatives). Prevents the failure mode of purely-critical analysis that produces nothing actionable.

**Implementation**: For every major thesis, the system runs six parallel passes — facts, intuition, risks, benefits, alternatives, meta — each as a structured output. The passes are held as legitimate simultaneous contributions, not combatants.

**Failure mode**: the Blue Hat (meta-thinking) gets neglected. Without strong meta-facilitation, the six modes produce disorganized output. CANOPTICON needs a Blue-Hat discipline that pulls the six into coherent synthesis.

- **Wired (W)** — encoded as a schema field, role prompt, or workflow step. The framework is invoked every time the relevant substrate state changes; an operator who uses CANOPTICON normally is using the framework whether they name it or not.

- **Discretionary (D)** — available to the operator at the prompt-iteration layer or as a vantage selector, but not wired into any default cascade. The role exists; the operator opts in by selecting a vantage or hand-editing a Skill prompt.

### Reading the table

Five of twelve are wired (Admiralty, Toulmin, IPCC, Brier, Popper) — these are the load-bearing methodology constraints. An operator cannot run CANOPTICON without invoking them; they are baked into schema columns and required prompt fields.

Four are implicit (Van Evera, Lakatos, Peirce, McLuhan) — these shape the system's structure without appearing as named function calls. The risk is that operators without canon literacy benefit from the discipline silently and lose it the moment they fork the prompts. The mitigation is documentation; this section is part of that.

Three are discretionary (Cynefin, Meadows, de Bono) — these are the v1.1 candidates. They are listed in the canon so operators can reach for them, but no default cascade invokes them. Promoting any of these to "wired" requires schema and prompt co-changes, and those changes need a worked example before being committed.

### The integration discipline

Adding a framework to the canon is cheap. Promoting a framework from canon to wired is expensive — it requires a schema field, a role prompt update, RLS test matrix entries, and a worked example. The promotion bar is: *the framework's discipline produces a different cascade outcome than not having it*. Frameworks that don't change outcomes stay in the canon as reference vocabulary.

The failure mode this section guards against is the inverse one: claiming a framework is "integrated" when it appears in a docstring but never in a prompt. If a framework name is in the canon's top-12 list and not in this mapping table, it is not yet integrated. That's a documentation bug.

## Closing note on operationalization

The most important thing this canon contributes isn't any single framework — it's the meta-principle that **CANOPTICON should not be methodologically monistic**. Different questions call for different methods. The methodology substrate should be a library, not a doctrine.

The first-class integrations (top 12) are always on — every investigation runs through them. The second-tier is called in when the question profile warrants it. The third-tier sits available but rarely activates.

The failure mode to avoid: turning the canon into an orthodoxy where every investigation must go through every framework. That produces analytical constipation. The skill is selection — knowing which traditions fit which problem profile.

The Confucian move (zhengming, rectification of names) is the last word: the whole canon is only useful if CANOPTICON's operators can identify when the names they're using correspond to the practices they're pointing at. Every methodology can be invoked performatively rather than actually — and when that happens, none of them help.
