# Archive — superseded documents

**Historical reference only. Do not design against anything in this folder.**

These documents describe earlier eras of Canopticon (the chat-first CMS and the
v1.0 thesis-platform on Next.js + Postgres) that no longer exist. They were
moved here in June 2026 when the repo docs were brought in line with the actual
built system.

- For the current architecture, see the repo root [`CLAUDE.md`](../../CLAUDE.md).
- For the current vision spec, see [`../canonical-spec-v2.4.md`](../canonical-spec-v2.4.md).
- For how the project got from there to here, see [`../LINEAGE.md`](../LINEAGE.md).

If anything in this folder contradicts those three, the archive is wrong — it
describes a system that has been replaced. Kept because the methodology canon,
glossary, and entity-resolution notes still contain useful thinking.

  superseded era — same caveat.
