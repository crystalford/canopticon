# Archived — the primitive engine (superseded)

These documents describe the visual engine that was **deleted** from the
working tree in the film-engine reset. They are kept because the reasoning
in them is often good and occasionally still true, and because the failures
they record are worth reading.

They are **not design authority for anything**. Three of them
(`CANOPTICON_CREATIVE_CONSTITUTION`, `CANOPTICON_PRIMITIVE_ATLAS`,
`CANOPTICON_PHASE0_MASTER_SPEC`) were listed in the root `CLAUDE.md` as
authority order, highest first — which meant a fresh session could have
faithfully rebuilt the 130-primitive engine from documents it had been told
to obey, days after it was removed. That is why this file exists.

The current authority is `docs/studio/CANOPTICON_FILM_ENGINE.md`.
